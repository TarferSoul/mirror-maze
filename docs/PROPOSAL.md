# 课程项目 Proposal：Mirror Maze／双世界迷宫

## 项目概述

Mirror Maze 是一个运行在浏览器中的单人网格解谜游戏。玩家可以在现实与镜像世界之间切换，同一坐标在不同世界具有不同的地形。玩家需要规划移动与穿越顺序，收集钥匙、触发机关，并最终抵达出口。

项目目标是在有限规模内实现完整的游戏流程，同时把数据结构与算法应用到实际交互中。提交内容包括可运行代码、五个关卡、项目说明与测试。

## 学习目标

1. 将游戏环境表示为二维数组，将游戏过程表示为离散状态转换。
2. 分离游戏规则、页面渲染、输入处理与存档，降低模块耦合。
3. 使用广度优先搜索计算最短路径，并提供可执行的单步提示。
4. 通过状态空间穷举验证关卡可解性与无死局性质。
5. 完成响应式界面、键盘和触屏输入、进度保存与自动化验证。

## 核心交互

玩家从关卡的初始坐标出发。移动只改变坐标，切换只改变当前世界。若目标格为墙壁或未开启的门，操作被拒绝；否则更新玩家位置并处理钥匙、机关、出口等事件。关卡完成后展示成绩、记录最佳表现并解锁下一关。

钥匙随玩家跨世界保留。机关永久开启两个世界的同名门。进入出口前必须收集全部钥匙；因此求解器不能只记录坐标，还必须跟踪钥匙与机关状态。

## 实现范围

| 模块     | 已实现内容                                             |
| -------- | ------------------------------------------------------ |
| 游戏流程 | 开始菜单、玩法说明、关卡选择、重玩、通关成绩、最终结局 |
| 关卡     | 5 个手工设计的递进关卡                                 |

## 技术方案

使用原生 JavaScript ES 模块、HTML 和 CSS。游戏规则不依赖浏览器 API，使用 Node.js 内置测试运行器即可验证。地图使用 DOM 网格渲染，存档使用浏览器 `localStorage`，音效使用 Web Audio API。静态文件可以通过普通 HTTP 服务运行，无需后端或第三方服务。

## 验收标准

- 五个关卡都可通过正常操作完成，而且必须切换世界。
- 不能穿墙、穿过未开启的门或跳过钥匙要求。
- 第四关必须激活 A 机关，第五关必须收集两把钥匙并激活 A/B 机关。
- 从所有可达状态均存在到出口的路径。
- 提示给出当前状态下最短路线的下一步，不直接移动玩家。
- 撤销恢复位置、世界、钥匙、机关与步数；重玩恢复初始状态。
- 完成关卡后解锁下一关；刷新后保留已解锁关卡与最佳成绩。
- 手机尺寸可使用屏幕按钮完成游戏，界面无横向溢出。
- 自动化测试通过，浏览器中可以完整走通五关。

## 展示安排（约 5 分钟）

1. 介绍双世界机制并演示第一关（1 分钟）。
2. 展示钥匙与跨界机关（1 分钟）。
3. 解释状态定义、BFS 与提示功能（1.5 分钟）。
4. 展示通关记录、响应式布局和验证结果（1 分钟）。
5. 说明关卡编辑器、随机生成等可扩展方向（0.5 分钟）。

## 可扩展方向

可添加关卡编辑器，把玩家绘制的两张地图转换成当前数据格式，再调用同一个求解器检查可解性。随机迷宫生成、计时挑战与更多机关可在核心版本之外逐步实现。
